- 2026-05-28 — Item 4 (chat persistence + chats store) — DONE.
  - Design choice: a dedicated `chats` TABLE, not a `kind='chat'` artifact. A chat is not a renderable artifact — it's a durable handle mapping a workspace → an opencode session id + a human title, ordered by recency for the sidebar history list (§10). opencode sessions are otherwise ephemeral with no durable list; this table IS that list.
